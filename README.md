# 🌌 AstroScope

**AstroScope** is an interactive astronomy dashboard built from scratch using **HTML5, CSS3 and Vanilla JavaScript**.

The project is designed as a portfolio/GitHub project and demonstrates modern front-end fundamentals without relying on a JavaScript framework.

## ✨ Features

- 🔭 Interactive celestial-object catalog
- 🔎 Live search
- 🪐 Category filtering
- ❤️ Favorites with `localStorage`
- 🌙 Dark / Light theme
- 📱 Responsive design
- 🪟 Interactive object details modal
- ⌨️ Escape-key modal control
- 🎨 CSS-generated astronomical visuals
- ⚡ No framework or build system required

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- CSS Grid / Flexbox
- LocalStorage
- Responsive Web Design

## 🚀 Run locally

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

For the best development experience, use **VS Code + Live Server**.
